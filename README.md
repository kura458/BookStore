# BookStore Practice

A beginner-friendly HTML practice project that builds a simple bookstore page. The page introduces a bookstore, displays two sample book cards, and includes **Buy Now**, **View Cart**, and **Checkout** buttons as interface elements.

## Page content

- Bookstore heading and introductory text
- Two sample book cards:
  - Sally's SciFi Adventure
  - Dave's Cooking Adventure
- Buy Now buttons for each book
- View Cart and Checkout buttons

## Technology

- HTML5

## Project structure

```text
BookStore/
├── BookStore_practice.html
└── README.md
```

## Run locally

1. Clone the repository:

   ```bash
   git clone https://github.com/kura458/BookStore.git
   ```

2. Open the project folder.
3. Open `BookStore_practice.html` in a web browser.

No installation or build tools are required.

## Current scope

This repository is an HTML structure and page-layout practice exercise. The buttons are currently presentational; shopping-cart and checkout functionality are not implemented.
